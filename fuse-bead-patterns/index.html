Reading a chart

How to read a fuse bead pattern

Each coloured cell is one bead. The letter in the cell is the palette code, and the legend on the last page tells you the colour name and how many you need. If a cell is blank, leave that peg empty.

Count in fives. The heavier grid lines mark every fifth row and column, which is why the chart is easier to follow than a plain pixel image. Work in blocks rather than one bead at a time, and check the outline before you start filling.

For a large pattern, print the PDF and tape the sheets together along the printed column and row ranges. The page footer tells you which slice of the chart you are holding.

Every chart includes

  • ✓One letter code per bead
  • ✓Exact count for each colour
  • ✓Total bead count
  • ✓A heavier line every 5 beads
  • ✓Column and row ranges for tiled pages
  • ✓A4 PDF at 100% scale
